# 六.npm

## 1.node

::: demo

```vue
<template>
  <div><button @click="getValue">点击发送请求</button> {{ value }}</div>
</template>

<script>
export default {
  data() {
    return {
      value: "",
    }
  },
  methods: {
    async getValue() {
     this.value = await this.$api.electron.npm('node -v')
   },
  }
}
</script>
```

:::
