# 三.文件操作(file)

## 1.文件上传

::: demo

```vue
<template>
  <div><button @click="getValue">请求</button> {{ value }}</div>
</template>

<script>
export default {
  data() {
    return {
      value: "",
    }
  },
  methods: {
    async getValue() {
     this.value = await this.$api.electron.file('upload')
   },
  }
}
</script>
```

:::
