# 五.其他

## 1.桌面通知

::: demo

```vue
<template>
  <div><button @click="getValue">请求</button> {{ value }}</div>
</template>

<script>
export default {
  data() {
    return {
      value: {
        title: '会议通知', 
        content:'明天下午3点有一个重要的会议。'
      },
    }
  },
  methods: {
    async getValue() {
      await this.$api.electron.notification(JSON.stringify(this.value))
   },
  }
}
</script>
```

:::

## 2.应用更新

::: demo

```vue
<template>
  <button @click="getValue">更新</button>
</template>

<script>
export default {
  methods: {
    async getValue() {
      await this.$api.electron.update()
   },
  }
}
</script>
```
