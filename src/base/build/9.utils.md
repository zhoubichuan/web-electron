# 七.系统相关

## 1.日历

::: demo

```vue
<template>
  <div>
    <button @click="getValue">点击发送请求</button> {{ value }}
    <input type="date" v-model="value.date">
    <input type="text" v-model="value.summary">
    <input type="text" v-model="value.location">
  </div>
</template>

<script>
export default {
  data() {
    return {
      value: {date:'', summary:'', location:''},
    }
  },
  methods: {
    async getValue() {
     this.value = await this.$api.electron.calendar(JSON.stringify(value))
   },
  }
}
</script>
```

:::
