# 一.应用

## 1.计算器

::: demo

```vue
<template>
    <button @click="handleOpen">打开计算器</button>
</template>

<script>
export default {
  methods: {
    async handleOpen() {
     this.value = await this.$api.electron.openApp('calc')
   },
  }
}
</script>
```

:::

## 3.邮箱

::: demo

```vue
<template>
  <div>
      <button @click="handleOpen">打开邮箱</button>
      <input type="text" v-model="value.email">
      <input type="text" v-model="value.subject">
      <input type="text" v-model="value.body">
  </div>
</template>

<script>
export default {
  data() {
    return {
      value: {
        email:'zhoubichuan@icloud.com', 
        subject:'你好', 
        body:'标题'
      },
    }
  },
  methods: {
    async handleOpen() {
     const data = `open mailto:${email}?subject=${encodeURIComponent(subject)}&body=${encodeURIComponent(body)}`
     await this.$api.electron.exec(data)
   },
  }
}
</script>
```

:::
