# 二.硬件信息

## 1.mac地址获取

::: demo

```vue
<template>
  <div><button @click="getValue">点击发送请求</button> {{ value }}</div>
</template>

<script>
export default {
  data() {
    return {
      value: "",
    }
  },
  methods: {
    async getValue() {
     this.value = await this.$api.electron.getMac()
   },
  }
}
</script>
```

:::
