# 二.系统信息(os)

## 1.mac地址

::: demo

```vue
<template>
  <div><button @click="getValue">请求</button> {{ value }}</div>
</template>

<script>
export default {
  data() {
    return {
      value: "",
    }
  },
  methods: {
    async getValue() {
     this.value = await this.$api.electron.os('mac')
   },
  }
}
</script>
```

## 6.内存信息

::: demo

```vue
<template>
  <div>
    <button @click="getValue">请求</button>总内存： {{ value }}
    <button @click="getValue2">请求</button> 空闲内存：{{ value2 }}
  </div>
</template>

<script>
export default {
  data() {
    return {
      value: "",
      value2: "",
    }
  },
  methods: {
    async getValue() {
     this.value = await this.$api.electron.os('totalmem')
   },
   async getValue2() {
     this.value2 = await this.$api.electron.os('freemem')
   },
  }
}
</script>
```
